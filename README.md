## 🪨 📄 ✂️ Featured Project: 01 - Rock, Paper, Scissors

### 📌 Overview
A command-line implementation of the classic game built in Python. The program generates a randomized computer choice, takes user input, maps choices using dictionaries, and evaluates game outcomes.

### 🧠 Key Concepts Practiced
* **Data Mapping:** Using Python dictionaries to convert string inputs into numerical keys for streamlined conditional comparisons.
* **Control Flow:** Navigating branching decisions through explicit `if/elif/else` statements to prioritize code readability.
* **Randomization:** Utilizing Python's built-in `random.choice()` function for dynamic AI moves.
* **String Formatting:** Using f-strings for clear terminal output.
