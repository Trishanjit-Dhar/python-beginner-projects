
# Python Beginner Projects

A collection of foundational, command-line Python projects demonstrating core programming principles, user input validation, control flow, and data handling.

## 📌 Projects Index

| Priority | Project Name | Directory | Primary Focus |
| :---: | :--- | :--- | :--- |
| **01** | **Rock-Paper-Scissors Game** | `01-rock-paper-scissors/` | Randomization, dictionary mappings, and conditional logic |
| **02** | **Expense Tracker** | `02-expense-tracker/` | Interactive CLI loops, list of tuples, and exception handling |

---

## 📝 Quick Project Summaries

* **01. Rock-Paper-Scissors Game:** A terminal-based game where the user challenges the computer to a classic match of Rock-Paper-Scissors with automated input validation and randomized computer moves.
* **02. Personal Expense Tracker:** A continuous console application that records categorized expenditures, formats records with currency precision, and tracks spending against a predefined monthly budget.
